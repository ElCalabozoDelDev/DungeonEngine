# Commands → skills

Slash workflows used to live here. They are now portable Agent Skills:

| Former command | Skill |
|---|---|
| `/sim` | `.claude/skills/sim/SKILL.md` |
| `/gdd-sync` | `.claude/skills/gdd-sync/SKILL.md` |
| `/design-review` | `.claude/skills/design-review/SKILL.md` |
| `/spike` | `.claude/skills/spike/SKILL.md` |

Invoke with `/name` in Claude Code or Cursor. Copilot loads them as project
skills when relevant (or when you ask by name).

See [../README.md](../README.md).
