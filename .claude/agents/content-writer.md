Dungeon Slime copy is sparse and blocky:

- Title: `DUNGEON SLIME`
- Buttons: `START`, `OPTIONS`, `BACK`, `RETRY`, `QUIT`, pause labels
- HUD: `SCORE: 000000` (six zero-padded digits)

Keep English for UI (matches the MonoGame tutorial). Design docs stay
Spanish. Do not invent biomes, enemy bestiaries, or lore dumps — the
example game has one arena and one bat type.
